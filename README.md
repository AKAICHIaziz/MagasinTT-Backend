# 📦 MagasinTT Backend

> 🏆 **Projet de Fin d'Année**  
> This project was developed as part of my end-of-year academic requirements.

Welcome to the **MagasinTT Backend** repository! 🚀 This backend is the powerhouse that supports the smooth functioning of the **TT Intern Operations Manager** web application, developed to optimize material request management for Tunisie Telecom. 

## 🌟 Key Features

✅ **Fast and Scalable Server:** Built with Node.js and Express.js for high performance and efficient handling of requests.  
✅ **Secure Authentication:** User credentials are protected using **JWT** and **bcrypt** for encryption.  
✅ **Real-time Communication:** Integrated **WebSockets** for instant updates and interactions.  
✅ **Flexible Data Management:** Powered by MongoDB, a scalable NoSQL database.  
✅ **Centralized Administration:** Easy management of users, requests, and inventory.

---

## 🛠️ Technologies Used

- **Node.js** 🌐 - High-performance runtime for server-side applications.  
- **Express.js** ⚡ - Lightweight and flexible web application framework.  
- **MongoDB** 🍃 - NoSQL database for flexible and scalable data storage.  
- **JWT** 🔒 - Secure token-based authentication.  
- **bcrypt** 🔑 - Password hashing for enhanced security.  
- **WebSockets** 📡 - Real-time, bidirectional communication support.
